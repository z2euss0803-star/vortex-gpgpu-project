# 硬件接线与供电

| 部件 | 当前项目连接 |
|---|---|
| 开发板 | Z11-P，XCZU11EG-FFVC1156-2-I |
| 供电 | 使用板卡原配电源与板级规定电源接口；现有证据未给出可独立确认的电压/极性，不根据器件电压猜测外部电源规格 |
| UART | USB转串口连接PC，115200；端口号按当前枚举识别 |
| 网络 | 板卡以太网与PC直连或同一受控局域网 |
| 显示 | miniDP连接兼容显示器；实际模式由KMS协商，不能用名义刷新率代替GPU FPS |
| 启动 | 匹配BOOT.BIN、image.ub、boot.scr的SD介质，启动模式按板卡手册确认 |
| 传感器/执行器 | 本交付采用图像文件输入和DP显示，未接外部传感器或执行器 |

固定S8 bit SHA256：`94ae9d3e6eb73ba55a8eec8c802e3818cd6b3a9be7e60542da5ae9459e3579e1`；XSA SHA256：`02e68160e21b01621fde1eac6e472810e0fe50cd1842acb3ab63469314355e94`。XSA内嵌bit与独立bit匹配。工具来源Vivado/Vitis 2020.1；Linux 5.4/PetaLinux 2020.1。

硬件使用四核，每核4 warp×4线程上下文，外部GPU AXI512bit。生成配置约96.968727MHz，不是仪器实测频率。S8每核8×8 INT16，48位累加。物理报告的原CDC/DRC和约束开放项见fpga/report，不因本次整理而关闭。

写SD、重配置PL、复位、首次供电和运行板测均为人工现场步骤。本仓库的下载/检查脚本不会执行这些操作。
