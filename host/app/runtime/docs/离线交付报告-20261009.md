## 审查修正与未覆盖项

- vecadd16名称不是16总元素：4核×4warp×4thread的固定诊断覆盖64元素，真实参数检查和工具改为每数组256字节；偏移4越界负例先失败后通过。
- PL容量统计排除PS程序保留，避免跨域统计下溢；失败断言与修复后结果保存。
- Ubuntu18的file曾显示截断的 `/lib/ld-`。独立默认链接探针及最终readelf均显示完整正确路径；撤回“编译器默认解释器坏了”的推断。显式链接器路径用于复现约束。
- CPU mock只模拟协议/内存与合成数值；不执行RISC-V/Vortex ISA。真板uaccess、MMIO顺序、非一致缓存、DMA停止性及GPU数值均未测试。
- 泛用CRT、低地址exit/性能写、Mosaic、H1扩展能力不在当前生产程序白名单，不能据公共mock loader通过自动批准。
- 通用旧后端只通过dispatch fixture验证隐式DCR与性能close路径；未启动实际simx/xrt/opae，完整旧系统回归仍开放。
